# Touch/tablet navigation — planned for v0.4.0

Touch home, tablet mode, on-screen keyboard integration, edge handles and the bar entry are excluded from the v0.3.0 desktop release. Their implementation and QA handoff remain in the separate v0.4.0 checkout.

Existing touch settings are retained as inactive metadata in v0.3.0. They do not activate input-device changes or background provider polling. Native touch, provider layering and hardware acceptance remain required for v0.4.0.
